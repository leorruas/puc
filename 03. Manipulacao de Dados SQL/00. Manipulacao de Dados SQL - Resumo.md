# Manipulação de dados com SQL

> **Contexto:** Este resumo acompanha a evolução incremental da disciplina de Manipulação de dados com SQL. O conteúdo estudado até aqui cobre os fundamentos da linguagem, sua relação com o modelo relacional e o funcionamento básico de SGBDs e ferramentas clientes.

## Visão geral

A disciplina aborda SQL aplicada a bancos de dados relacionais. O percurso começa pela linguagem e pela estrutura relacional sobre a qual ela atua e deve avançar, conforme as aulas forem estudadas, para definição de estruturas, manipulação e consulta de dados, controle de acesso, junções, agregações, subconsultas e outros recursos de interação com SGBDs relacionais.

## Pontes conceituais

Manipulação de dados com SQL dá continuidade a [[02. Modelagem de Dados/00. Modelagem de Dados - Resumo|Modelagem de dados]]. A modelagem define como os dados são estruturados e relacionados; SQL fornece os comandos usados para implementar, consultar e modificar essas estruturas em um SGBD.

Há também uma ponte importante com [[05. Desenvolvimento Web Back-End/01. Arquitetura de software e cliente-servidor#O que é domínio|Desenvolvimento Web Back-End]]. A palavra **domínio** aparece nas duas áreas com sentidos diferentes: no modelo relacional, representa o conjunto de valores válidos de um atributo; em arquitetura e desenvolvimento Back-End, representa a área de problema, seus conceitos e regras. O [[02. Bancos de dados relacionais e SGBDs#A palavra domínio muda de sentido em Web Back-End|artigo 02]] registra essa distinção explicitamente.

Para revisão rápida dos termos da disciplina, consultar [[Glossário de conceitos|Glossário de conceitos]].
