# Manipulação de Dados com SQL

## Visão Geral

A disciplina aborda a linguagem SQL aplicada a bancos de dados relacionais, partindo de seus fundamentos e avançando para definição de estruturas, manipulação e consulta de dados, controle de acesso, junções, agregações, subconsultas e outros recursos usados na interação com SGBDs relacionais.

## Conexão com Modelagem de Dados

Manipulação de Dados com SQL dá continuidade ao conteúdo de [[02. Modelagem de Dados/00. Modelagem de Dados - Resumo|Modelagem de Dados]]. A modelagem define como os dados são estruturados e relacionados; SQL fornece os comandos usados para definir essas estruturas no SGBD e para consultar, inserir, alterar e remover seus dados.

Os dois primeiros artigos deixam explícita a passagem entre as disciplinas: o artigo 01 apresenta SQL como linguagem; o artigo 02 retoma a estrutura relacional sobre a qual essa linguagem atua e diferencia o banco, o SGBD servidor e as ferramentas clientes utilizadas para acessá-lo.
