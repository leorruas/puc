# Modelagem de dados

## Visão geral

A disciplina consolida a passagem do problema do mundo real para estruturas de banco de dados: abstração, arquitetura de SGBDs, modelo entidade-relacionamento, modelo relacional, chaves e integridade, mapeamento do DER, normalização até a 3ª forma normal, modelos não relacionais e segurança de dados.

Há uma continuidade direta com [[03. Manipulação de Dados SQL/00. Manipulação de Dados SQL - Resumo|Manipulação de dados SQL]]: Modelagem de dados define estruturas, restrições e decisões de projeto; SQL materializa e opera essas decisões por meio de comandos de definição, manipulação, consulta, transação e controle de acesso.

## Pontos centrais até agora

Modelagem de dados é um processo de abstração. O problema começa no mini-mundo e passa por decisões conceituais, lógicas e físicas até chegar à implementação. O MER descreve entidades, atributos, relacionamentos e regras do domínio; o modelo relacional reorganiza essas decisões em relações, atributos, chaves e restrições.

As chaves têm funções diferentes dentro dessa passagem. Chaves candidatas identificam tuplas, uma delas pode ser escolhida como chave primária e chaves estrangeiras preservam referências entre relações. Integridade de domínio, entidade, chave e referência delimitam quais estados do banco são válidos.

O mapeamento não é uma conversão mecânica de desenho para tabela. Cardinalidade, participação, identidade, atributos do relacionamento e especializações determinam onde FKs ficam, quando uma nova relação é necessária e como hierarquias podem ser representadas. Depois do mapeamento, a normalização verifica dependências funcionais para reduzir redundância estrutural e anomalias.

O modelo relacional não é a única forma de organizar dados. Modelos hierárquicos, de rede, orientados a objetos e famílias NoSQL adotam estruturas e compromissos diferentes. A escolha do modelo precisa acompanhar o tipo de problema, os padrões de acesso e as necessidades de escala. Em qualquer abordagem, segurança atravessa todas as camadas: identidade, privilégios, proteção técnica, rastreabilidade e tratamento adequado de dados pessoais.
