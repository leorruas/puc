# Prompts de Estudo (LLM) - Fundamentos de Redes de Computadores

Use estes templates de prompt prontos com seu LLM (ChatGPT, Gemini, Claude, etc.) para sanar dúvidas, gerar exemplos práticos e exercitar seu conhecimento nesta disciplina.

---

### Explicador do Fluxo de Protocolos
```text
Explique passo a passo o que acontece no modelo TCP/IP (em cada camada) quando eu digito 'https://www.google.com' no navegador e aperto Enter. Detalhe o papel do DNS, TCP Handshake e requisição HTTP.
```

### Resolução de Problemas de Rede
```text
Aja como um Engenheiro de Redes. Meu servidor web está apresentando o seguinte sintoma: [SINTOMA, ex: timeout, erro 502]. Quais comandos (como ping, traceroute, netstat, curl) eu devo rodar para diagnosticar a causa raiz?
```
