# Prompts de Estudo (LLM) - Engenharia de Requisitos de Software

Use estes templates de prompt prontos com seu LLM (ChatGPT, Gemini, Claude, etc.) para sanar dúvidas, gerar exemplos práticos e exercitar seu conhecimento nesta disciplina.

---

### Gerador de User Stories
```text
Transforme a seguinte funcionalidade em 3 Histórias de Usuário completas no padrão 'Como um..., Eu quero..., Para que...'. Inclua critérios de aceitação detalhados usando a sintaxe Given/When/Then (Dado/Quando/Então):
[FUNCIONALIDADE]
```

### Identificador de Requisitos Não-Funcionais
```text
Com base na descrição do sistema a seguir, identifique possíveis requisitos não-funcionais (segurança, performance, usabilidade, disponibilidade) importantes que devem ser considerados:
[DESCRIÇÃO DO SISTEMA]
```
