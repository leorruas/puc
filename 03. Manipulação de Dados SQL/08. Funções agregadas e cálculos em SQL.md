# Funções agregadas e cálculos em SQL

> **Contexto:** Este artigo apresenta funções agregadas usadas com `SELECT` para resumir conjuntos de dados: `AVG`, `COUNT`, `MAX`, `MIN` e `SUM`. Também diferencia `COUNT(*)` de `COUNT(coluna)`, mostra como valores `NULL` afetam os cálculos, combina agregações com filtros em `WHERE` e introduz aliases e expressões aritméticas simples.

Consultas SQL não servem apenas para recuperar linhas. Também podem produzir **resumos numéricos** sobre um conjunto de dados, como quantidade de registros, média, soma, maior valor e menor valor.

Essas operações são realizadas por **funções agregadas** ou **funções de agregação**. Em vez de retornar um valor por linha, elas condensam vários valores em um resultado calculado.

## 1. Visão geral das funções agregadas

As funções estudadas são:

| Função | Resultado |
| --- | --- |
| `AVG(coluna)` | média dos valores não nulos da coluna |
| `COUNT(coluna)` | quantidade de valores não nulos da coluna |
| `COUNT(*)` | quantidade de linhas |
| `MAX(coluna)` | maior valor não nulo da coluna |
| `MIN(coluna)` | menor valor não nulo da coluna |
| `SUM(coluna)` | soma dos valores não nulos da coluna |

Uma característica importante é que `AVG`, `COUNT(coluna)`, `MAX`, `MIN` e `SUM` desconsideram valores `NULL`.

## 2. `AVG`: calcular a média

`AVG` vem de *average* e calcula a média dos valores de uma coluna.

Para obter o preço médio dos produtos:

```sql
SELECT AVG(Preco)
FROM Produto;
```

Se a tabela contiver preços como:

```text
80
460
1000
1500
3500
```

a função produz um único resultado correspondente à média desses valores.

Valores `NULL` não participam do cálculo. Portanto, um produto sem preço informado não é tratado como preço zero; sua ausência simplesmente não entra na média.

## 3. Alias: dar um nome mais claro ao resultado

O nome automático de uma coluna calculada pode ficar pouco legível, especialmente quando o resultado aparece como algo semelhante a `AVG(Preco)`.

Um **alias** dá um nome temporário à coluna produzida pelo resultado da consulta.

> **Aprofundamento técnico:** uma forma comum de declarar um alias é usar `AS`.

```sql
SELECT AVG(Preco) AS PrecoMedio
FROM Produto;
```

Sem alias, o resultado pode aparecer assim:

| AVG(Preco) |
| ---: |
| 1308 |

Com o alias:

| PrecoMedio |
| ---: |
| 1308 |

O ponto principal é que **`PrecoMedio` não passa a existir como coluna da tabela `Produto`**. O alias funciona apenas como uma etiqueta para a coluna retornada por aquela query.

Também não existe um valor persistente sendo mantido automaticamente. A expressão `AVG(Preco)` é calculada quando a consulta é executada. Se os preços armazenados mudarem e a mesma consulta for executada novamente, a média será recalculada com os dados atuais.

Por isso, esta consulta é válida:

```sql
SELECT AVG(Preco) AS PrecoMedio
FROM Produto;
```

mas esta outra só seria válida se `PrecoMedio` fosse realmente uma coluna definida na tabela:

```sql
SELECT PrecoMedio
FROM Produto;
```

O modelo mental é: **a expressão produz o valor; o alias apenas dá um nome ao resultado**.

## 4. `COUNT(*)`: contar linhas

`COUNT(*)` conta quantas linhas participam do resultado.

Para saber quantos produtos estão cadastrados:

```sql
SELECT COUNT(*)
FROM Produto;
```

Se houver cinco linhas na tabela, o resultado será:

```text
5
```

Também podemos usar um alias:

```sql
SELECT COUNT(*) AS QuantidadeProdutos
FROM Produto;
```

## 5. `COUNT(coluna)`: contar valores não nulos

`COUNT(coluna)` não é exatamente a mesma coisa que `COUNT(*)`.

Considere uma tabela com cinco produtos, mas dois deles sem preço:

| Produto | Preco |
| --- | ---: |
| Produto A | 3500 |
| Produto B | 1000 |
| Produto C | `NULL` |
| Produto D | `NULL` |
| Produto E | 80 |

Então:

```sql
SELECT COUNT(*)
FROM Produto;
```

retorna `5`, porque existem cinco linhas.

Já:

```sql
SELECT COUNT(Preco)
FROM Produto;
```

retorna `3`, porque apenas três linhas possuem um valor não nulo em `Preco`.

O modelo mental é:

> **`COUNT(*)` conta linhas; `COUNT(coluna)` conta valores não nulos daquela coluna.**

## 6. Agregações também podem usar `WHERE`

As funções agregadas podem ser combinadas com filtros.

Para contar apenas produtos da categoria `1`:

```sql
SELECT COUNT(*) AS Quantidade
FROM Produto
WHERE Categoria = '1';
```

`WHERE` restringe as linhas consideradas e, depois, a função agregada resume esse conjunto filtrado.

A mesma ideia vale para as demais funções.

Por exemplo, para calcular o preço médio somente da categoria `1`:

```sql
SELECT AVG(Preco) AS PrecoMedio
FROM Produto
WHERE Categoria = '1';
```

Os filtros e operadores usados em `WHERE` são aprofundados em [[07. Operadores e condições em consultas SQL|07. Operadores e condições em consultas SQL]].

## 7. `MAX`: encontrar o maior valor

`MAX` retorna o maior valor de uma coluna.

Para obter o maior preço:

```sql
SELECT MAX(Preco) AS MaiorPreco
FROM Produto;
```

Também é possível restringir o cálculo:

```sql
SELECT MAX(Preco) AS MaiorPreco
FROM Produto
WHERE Categoria = '3';
```

Nesse caso, o maior valor é procurado somente entre os produtos da categoria `3`.

Valores `NULL` não são considerados.

## 8. `MIN`: encontrar o menor valor

`MIN` funciona de forma análoga a `MAX`, mas retorna o menor valor.

```sql
SELECT MIN(Preco) AS MenorPreco
FROM Produto;
```

Com filtro:

```sql
SELECT MIN(Preco) AS MenorPreco
FROM Produto
WHERE Categoria = '1';
```

Assim como `MAX`, `MIN` ignora valores `NULL`.

## 9. `SUM`: somar valores

`SUM` calcula o somatório dos valores de uma coluna.

Para somar os preços de todos os produtos:

```sql
SELECT SUM(Preco) AS SomaPrecos
FROM Produto;
```

Também podemos filtrar antes da soma:

```sql
SELECT SUM(Preco) AS SomaPrecos
FROM Produto
WHERE Fornecedor = '002';
```

Nesse caso, apenas os preços das linhas cujo fornecedor é `002` participam da soma.

Se o filtro não encontrar valores para agregar, `SUM` pode retornar `NULL`.

## 10. Valores `NULL` e funções agregadas

A distinção entre ausência de valor e valor zero é especialmente importante em agregações.

Considere:

| Produto | Preco |
| --- | ---: |
| A | 100 |
| B | 200 |
| C | `NULL` |

Então:

- `COUNT(*)` considera as três linhas;
- `COUNT(Preco)` considera apenas os dois preços informados;
- `AVG(Preco)` calcula a média entre `100` e `200`;
- `SUM(Preco)` soma apenas `100 + 200`;
- `MAX(Preco)` e `MIN(Preco)` procuram extremos apenas entre os valores existentes.

`NULL` não equivale a zero. Se fosse zero, ele participaria dos cálculos e mudaria os resultados.

## 11. Funções agregadas produzem resumos

Considere:

```sql
SELECT Preco
FROM Produto;
```

Essa consulta pode retornar vários preços, um por linha.

Já:

```sql
SELECT AVG(Preco)
FROM Produto;
```

produz um valor resumido: a média.

O mesmo raciocínio vale para `COUNT`, `MAX`, `MIN` e `SUM`. O objetivo é transformar um conjunto de valores em uma informação consolidada.

## 12. Expressões aritméticas em `SELECT`

SQL também pode avaliar expressões aritméticas que **não são funções agregadas**.

Por exemplo:

```sql
SELECT 2 + 3;
```

retorna:

```text
5
```

Outras operações aritméticas também podem ser utilizadas, como subtração, multiplicação e divisão:

```sql
SELECT 10 - 4;
SELECT 5 * 3;
SELECT 20 / 4;
```

Essas expressões calculam diretamente o valor solicitado.

## 13. Expressões com colunas

Uma expressão também pode utilizar valores de uma coluna.

Por exemplo:

```sql
SELECT Nome, Preco, Preco * 2 AS PrecoDobrado
FROM Produto;
```

Nesse caso, a expressão `Preco * 2` é calculada para cada linha retornada.

Isso é diferente de uma função agregada:

```sql
SELECT SUM(Preco)
FROM Produto;
```

`Preco * 2` produz um cálculo por linha; `SUM(Preco)` consolida vários valores em um resultado agregado.

## 14. Constantes e quantidade de linhas

Uma expressão constante pode ser combinada com `FROM`.

Sem tabela:

```sql
SELECT 2 + 3;
```

há um único resultado.

Com uma tabela:

```sql
SELECT 2 + 3
FROM Produto;
```

a mesma expressão é avaliada para cada linha considerada pela consulta. Se `Produto` tiver cinco linhas, o resultado conterá cinco linhas com o valor `5`.

Isso reforça uma ideia central de `SELECT`: aquilo que aparece na lista de seleção define **o que será apresentado**, enquanto `FROM` determina a origem e a quantidade de linhas sobre as quais a consulta opera.

## 15. Script de prática

```sql
-- média dos preços
SELECT AVG(Preco) AS PrecoMedio
FROM Produto;

-- quantidade total de produtos
SELECT COUNT(*) AS QuantidadeProdutos
FROM Produto;

-- quantidade de preços informados
SELECT COUNT(Preco) AS PrecosInformados
FROM Produto;

-- quantidade de produtos da categoria 1
SELECT COUNT(*) AS QuantidadeCategoria1
FROM Produto
WHERE Categoria = '1';

-- maior preço
SELECT MAX(Preco) AS MaiorPreco
FROM Produto;

-- maior preço da categoria 3
SELECT MAX(Preco) AS MaiorPrecoCategoria3
FROM Produto
WHERE Categoria = '3';

-- menor preço
SELECT MIN(Preco) AS MenorPreco
FROM Produto;

-- soma de todos os preços
SELECT SUM(Preco) AS SomaPrecos
FROM Produto;

-- soma dos preços de um fornecedor específico
SELECT SUM(Preco) AS SomaFornecedor
FROM Produto
WHERE Fornecedor = '002';

-- expressão aritmética sem tabela
SELECT 2 + 3 AS Resultado;

-- cálculo executado para cada linha
SELECT Nome, Preco, Preco * 2 AS PrecoDobrado
FROM Produto;
```

## Pontos que costumam gerar confusão

- **`COUNT(*)` e `COUNT(coluna)` não são equivalentes.** O primeiro conta linhas; o segundo conta valores não nulos da coluna.
- **`NULL` não é zero.** Valores nulos são desconsiderados por `AVG`, `COUNT(coluna)`, `MAX`, `MIN` e `SUM`.
- **`WHERE` filtra antes do resumo pretendido pela consulta.** A função agregada considera apenas as linhas que satisfazem a condição.
- **Alias não cria nem renomeia uma coluna da tabela.** Ele é apenas um nome temporário no resultado da query; o valor calculado é produzido novamente a cada execução.
- **`MAX` e `MIN` procuram extremos; `SUM` soma; `AVG` calcula média.**
- **Expressão aritmética não é função agregada.** `Preco * 2` calcula um valor por linha, enquanto `SUM(Preco)` consolida vários valores.
- **Adicionar `FROM` a uma expressão constante pode repetir o resultado.** A expressão é avaliada para cada linha considerada pela consulta.
