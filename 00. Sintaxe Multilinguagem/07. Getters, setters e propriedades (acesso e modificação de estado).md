# 07. Getters, setters e propriedades (acesso e modificação de estado)

> **Contexto:** Estudo das formas de leitura e escrita de atributos privados em orientação a objetos: a diferença entre métodos explícitos (`GetSaldo()` / `SetSaldo()`), propriedades nativas do C# (`get` / `set`), a distinção fundamental em relação a verbos HTTP (`GET` / `POST` na Web) e explicações didáticas via Técnica de Feynman.

---

## 1. O que são Getters e Setters? (Técnica de Feynman)

Quando criamos uma classe orientada a objetos (TAD), guardamos os dados em **atributos privados** (`private double _saldo;`). Como o mundo externo está proibido de tocar diretamente nessa variável, precisamos de **portas de acesso controladas**:

* **Getter (`Get` / Leitura):** Uma janela de vidro blindado. O cliente olha para dentro e **lê o valor** do saldo, mas não consegue colocar as mãos no dinheiro.
* **Setter (`Set` / Escrita):** Uma portinhola de depósito com segurança. O cliente entrega um novo valor, o método valida se o valor é aceitável (ex.: impede valores negativos) e só então atualiza a variável interna.

---

## 2. Diferença crucial: `Get/Set` em POO vs. `GET/POST` em Web/HTTP

É muito comum no início haver confusão entre esses termos parecidos:

| Conceito | Contexto | O que faz? | Onde é usado? |
| --- | --- | --- | --- |
| **`Get` / `Set` (POO)** | **Orientação a Objetos** | Métodos ou propriedades para ler (`get`) ou alterar (`set`) atributos privados de uma classe. | No código C#, Java, Python (`GetSaldo()`, `get { return _saldo; }`). |
| **`GET` / `POST` (HTTP)** | **Protocolo Web / APIs REST** | Verbos de comunicação de rede entre Navegador e Servidor (`GET` solicita dados de uma página, `POST` envia um formulário para gravação). | Em requisições de rede, APIs Web Back-End e formulários HTML. |

---

## 3. As duas formas de implementar no C#: Métodos vs. Propriedades

No C#, existem duas maneiras oficiais de permitir acesso controlado ao estado:

### Forma 1: Método Convencional (`GetSaldo()`)
É uma função pública comum que simplesmente retorna o valor do atributo privado:

```csharp
public class Conta 
{
    private double _saldo;

    // Método Getter clássico: função explícita com retorno
    public double GetSaldo() 
    {
        return _saldo; // Apenas devolve o valor guardado em _saldo
    }
}

// Uso no código cliente:
Conta c = new Conta(1000, DateTime.Now);
Console.WriteLine(c.GetSaldo()); // Invocação explícita de função com parênteses ()
```

### Forma 2: Propriedade Nativa do C# (`DataCriacao { get; }`)
O C# possui um recurso elegante chamado **Propriedades**, que une a segurança de um método com a sintaxe limpa de uma variável:

```csharp
public class Conta 
{
    private DateTime _criacao;

    // Propriedade Somente Leitura (Read-Only Property)
    public DateTime DataCriacao 
    {
        get { return _criacao; } // Bloco 'get' devolve o valor de _criacao
    }
}

// Uso no código cliente:
Conta c = new Conta(1000, DateTime.Now);
Console.WriteLine(c.DataCriacao); // Acessa como se fosse uma variável, mas sem parênteses!
```

## 4. Comparativo Multilinguagem de Getters e Setters

### C#
```csharp
public class Conta 
{
    private double _saldo;

    // Forma por Propriedade com get e set protegido
    public double Saldo 
    {
        get { return _saldo; }
        private set { if (value >= 0) _saldo = value; }
    }

    // Forma por Método Get
    public double GetSaldo() => _saldo;
}
```

### Java
```java
public class Conta {
    private double saldo;

    // Em Java, a convenção padrão é sempre usar métodos getX() e setX()
    public double getSaldo() {
        return this.saldo;
    }

    public void setSaldo(double novoSaldo) {
        if (novoSaldo >= 0) {
            this.saldo = novoSaldo;
        }
    }
}
```

### Python
```python
class Conta:
    def __init__(self, saldo):
        self._saldo = saldo

    # Em Python usa-se o decorador @property para criar getters
    @property
    def saldo(self):
        return self._saldo

    @saldo.setter
    def saldo(self, novo_saldo):
        if novo_saldo >= 0:
            self._saldo = novo_saldo
```
