# 03. Estruturas de repetição (while, for, do-while)

> **Contexto:** Estudo das estruturas de iteração pré-testadas (`while`), contadas (`for`) e pós-testadas (`do-while`) em C#, Java, Python e JavaScript.

---

## 1. Repetição pré-testada (`while`)

### Como funciona
Avalia a condição **antes** de cada iteração. Se a condição for falsa na primeira tentativa, o bloco nunca é executado.

### C# / Java / JavaScript
```csharp
int contador = 1;
while (contador <= 5) {
    Console.WriteLine($"Contagem: {contador}");
    contador++;
}
```

### Python
```python
contador = 1
while contador <= 5:
    print(f"Contagem: {contador}")
    contador += 1
```

---

## 2. Repetição contada (`for`)

### Como funciona
Ideal para iterações com limite conhecido. Agrupa inicialização, condição e incremento.

### C# / Java / JavaScript
```csharp
for (int i = 0; i < 5; i++) {
    Console.WriteLine($"Índice: {i}");
}
```

### Python
```python
for i in range(5):
    print(f"Índice: {i}")
```

---

## 3. Repetição pós-testada (`do-while`)

### Como funciona
Executa o bloco **pelo menos uma vez** antes de testar a condição no final. Ideal para menus interativos.

### C# / Java / JavaScript
```csharp
int opcao;
do {
    opcao = LerOpcao();
} while (opcao != 0);
```

### Python (Emulação)
```python
while True:
    opcao = ler_opcao()
    if opcao == 0:
        break
```
