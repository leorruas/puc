# Templates server-side e sintaxe incorporada: Razor e PHP

> **Contexto:** Esta nota compara duas formas de incorporar lógica de servidor em templates HTML: Razor, no ecossistema ASP.NET Core, e PHP. O objetivo é reconhecer onde termina a marcação HTML, onde começa o código executado no servidor e como valores, condições e repetições são usados para produzir HTML dinâmico.

## 1. A ideia comum

Nos dois casos, o arquivo mistura:

- HTML que fará parte da resposta;
- pontos de inserção de valores;
- estruturas condicionais;
- estruturas de repetição;
- pequenos blocos de lógica de apresentação.

O resultado final enviado ao navegador é HTML. O código C# de Razor ou o código PHP é processado no servidor.

## 2. Inserindo um valor no HTML

### Razor

```cshtml
<p>@Model.Nome</p>
```

O `@` inicia uma expressão Razor. `Model.Nome` é avaliado no servidor e seu valor é inserido na saída.

### PHP

```php
<p><?= $nome ?></p>
```

`<?= ... ?>` é uma forma curta de escrever um valor na saída HTML.

A ideia conceitual é a mesma: **avaliar uma expressão no servidor e inserir o resultado na marcação**.

## 3. Blocos de código

### Razor

```cshtml
@{
    var titulo = "Detalhes";
}
```

`@{ ... }` delimita um bloco C# que será executado durante a renderização.

### PHP

```php
<?php
$titulo = "Detalhes";
?>
```

`<?php ... ?>` delimita código PHP executado no servidor.

## 4. Condicionais

### Razor

```cshtml
@if (Model.Ativo)
{
    <span>Ativo</span>
}
else
{
    <span>Inativo</span>
}
```

### PHP

```php
<?php if ($ativo): ?>
    <span>Ativo</span>
<?php else: ?>
    <span>Inativo</span>
<?php endif; ?>
```

A estrutura lógica continua sendo uma seleção `if/else`; o que muda é a sintaxe usada para alternar entre código e HTML.

Para a estrutura condicional em si, consulte [[00. Sintaxe Multilinguagem/02. Estruturas condicionais (if, else, switch)|Estruturas condicionais]].

## 5. Repetindo marcação

### Razor

```cshtml
@foreach (var pessoa in Model)
{
    <li>@pessoa.Nome</li>
}
```

### PHP

```php
<?php foreach ($pessoas as $pessoa): ?>
    <li><?= $pessoa["nome"] ?></li>
<?php endforeach; ?>
```

Nos dois casos, a repetição produz vários trechos de HTML a partir de uma coleção.

Para revisar estruturas de repetição, consulte [[00. Sintaxe Multilinguagem/03. Estruturas de repetição (while, for, do-while)|Estruturas de repetição]].

## 6. Uma diferença importante de organização

A possibilidade de colocar código dentro de um template não significa que regras de negócio devam ser implementadas ali.

Em Razor MVC, a View deve concentrar lógica de **apresentação**. O Controller coordena a requisição, Models e serviços podem concentrar regras do domínio, e o `DbContext` coordena persistência.

Em PHP também é possível misturar muita lógica diretamente no template, mas separar responsabilidades continua sendo importante para legibilidade e manutenção.

## 7. Tabela comparativa

| Objetivo | Razor | PHP |
| --- | --- | --- |
| Inserir valor | `@Model.Nome` | `<?= $nome ?>` |
| Bloco de código | `@{ ... }` | `<?php ... ?>` |
| Condicional | `@if (...) { ... }` | `<?php if (...): ?> ... <?php endif; ?>` |
| Repetição | `@foreach (...) { ... }` | `<?php foreach (...): ?> ... <?php endforeach; ?>` |
| Saída final | HTML | HTML |

A sintaxe muda, mas o princípio permanece: **o servidor executa código para decidir qual HTML será produzido**.
