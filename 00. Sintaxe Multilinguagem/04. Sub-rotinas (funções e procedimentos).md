# 04. Sub-rotinas (funções e procedimentos)

> **Contexto:** Estudo prático da diferença sintática entre Funções (abstração de expressão com retorno) e Procedimentos (abstração de comando `void`), explicando didaticamente por que procedimentos usam `void` em C#, Java e C++.

---

## 1. Como funciona (Técnica de Feynman)

Imagine uma cozinha profissional com dois tipos de funcionários:

1. **O Balconista / Garçom (Procedimento - `void`):**
   - **Papel:** Ele recebe uma instrução de ação: *"Limpe a mesa 4 e arrume as cadeiras"*.
   - **O que acontece?** Ele vai até lá, limpa a mesa e faz o trabalho. Ao terminar, ele **não te entrega nenhum objeto ou número na mão**. O trabalho dele foi **fazer uma ação no mundo real** (efeito colateral).
   - **No C#:** Como ele não devolve nenhum dado para ser guardado em uma variável, dizemos que a resposta dele é **"Vazia" (`void`)**.

2. **O Cozinheiro (Função - Com `return`):**
   - **Papel:** Você dá os ingredientes (entradas) e diz: *"Calcule o peso da receita e me devolva o valor"*.
   - **O que acontece?** Ele pesa os ingredientes e **te entrega de volta um número na mão** (ex.: `500` gramas).
   - **No C#:** Você obrigatoriamente declara o tipo de dado que ele vai te entregar (`int`, `double`, `string`) e o código termina com `return valor;`.

---

## 2. Por que os procedimentos usam `void` em C#?

### A razão de arquitetura da linguagem:
1. **Diferença de propósito:**
   Uma **Função** é usada dentro de uma **atribuição ou conta** (ex.: `int total = Somar(2, 3);`).
   Já um **Procedimento** é chamado como uma **instrução isolada** (ex.: `Console.WriteLine("Olá");` ou `LimparTela();`). Você não faz `int x = LimparTela();` porque limpar a tela não gera um número para ser guardado em `x`.

2. **Declaração explícita no compilador C#:**
   Em linguagens estaticamente tipadas (C#, Java, C++), o compilador exige saber exatamente qual tipo de dado sai de qualquer método. Como o procedimento **não devolve nada**, a linguagem criou a palavra-chave reservada **`void`** para representar essa ausência de retorno.

---

## 3. Comparativo multilinguagem

### C#
```csharp
// Procedimento: apenas executa ações (limpar tela, escrever). Retorno é void.
public static void ExibirMensagem(string texto) {
    Console.WriteLine(texto);
}

// Função: calcula e devolve obrigatoriamente um int com a palavra 'return'
public static int Somar(int a, int b) {
    return a + b;
}
```

### Java
```java
// Procedimento (void)
public static void exibirMensagem(String texto) {
    System.out.println(texto);
}

// Função (int)
public static int somar(int a, int b) {
    return a + b;
}
```

### Python
```python
# Procedimento em Python: não precisa declarar 'void', retorna 'None' implicitamente
def exibir_mensagem(texto):
    print(texto)

# Função em Python: usa a palavra-chave 'return'
def somar(a, b):
    return a + b
```

### JavaScript
```javascript
// Procedimento em JS: não declara tipo, retorna 'undefined' se não usar return
function exibirMensagem(texto) {
    console.log(texto);
}

// Função em JS: usa return para devolver o valor
function somar(a, b) {
    return a + b;
}
```
