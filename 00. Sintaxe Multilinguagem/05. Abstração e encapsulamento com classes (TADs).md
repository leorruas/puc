# 05. Abstração e encapsulamento com classes (TADs)

> **Contexto:** Estudo prático da criação de classes, proteção de estado interno (atributos privados) e exposição de métodos públicos em C#, Java e Python através da Técnica de Feynman.

---

## 1. Como funciona (Técnica de Feynman)

Pense em um **Caixa Eletrônico (ATM)**:
* **Atributos Privados (`private`):** O cofre interno e as gavetas de cédulas. Ficam escondidos para que ninguém altere o saldo de forma fraudulenta ou incorreta.
* **Operações Públicas (`public`):** A tela e o teclado (`Sacar()`, `Depositar()`). São os únicos pontos de contato onde qualquer operação passa por validações de regras de negócio antes de tocar no dinheiro.

---

## 2. Comparativo multilinguagem

### C#
```csharp
public class ContaBancaria 
{
    // Atributo privado: protegido contra acesso externo direto
    private double _saldo;

    // Construtor: inicialização segura
    public ContaBancaria(double saldoInicial) 
    {
        _saldo = saldoInicial;
    }

    // Método público: altera o estado interno com validação
    public void Depositar(double quantia) 
    {
        if (quantia > 0) 
            _saldo += quantia;
    }

    // Consulta de estado: expõe o valor sem permitir modificação direta
    public double GetSaldo() => _saldo;
}
```

### Java
```java
public class ContaBancaria {
    private double saldo;

    public ContaBancaria(double saldoInicial) {
        this.saldo = saldoInicial;
    }

    public void depositar(double quantia) {
        if (quantia > 0) {
            this.saldo += quantia;
        }
    }

    public double getSaldo() {
        return this.saldo;
    }
}
```

### Python
```python
class ContaBancaria:
    def __init__(self, saldo_inicial):
        self._saldo = saldo_inicial # Prefixo _ indica atributo privado por convenção

    def depositar(self, quantia):
        if quantia > 0:
            self._saldo += quantia

    def get_saldo(self):
        return self._saldo
```
