# Prompts de Estudo (LLM) - Desenvolvimento Web Back-End

Use estes templates de prompt prontos com seu LLM (ChatGPT, Gemini, Claude, etc.) para sanar dúvidas, gerar exemplos práticos e exercitar seu conhecimento nesta disciplina.

---

### Criador de Boilerplate de API
```text
Gere uma estrutura básica de API RESTful em [TECNOLOGIA, ex: Node.js/Express ou Python/FastAPI] para gerenciar [ENTIDADE, ex: Produtos/Usuários]. Inclua rotas de CRUD completo e boas práticas de tratamento de erros.
```

### Modelagem de API REST
```text
Como projetar os endpoints RESTful ideais para o seguinte caso de uso: [DESCREVA O CASO DE USO]? Liste os caminhos (URIs), métodos HTTP corretos, códigos de status esperados e o formato JSON de requisição e resposta.
```
