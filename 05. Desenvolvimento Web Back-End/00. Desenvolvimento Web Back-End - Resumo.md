## Pontos centrais até agora

Arquitetura não é apenas uma escolha de framework ou linguagem. Ela representa decisões sobre organização, responsabilidades, relações e princípios de evolução do sistema. Em aplicações Web, a separação cliente-servidor ajuda a localizar responsabilidades: o cliente inicia requisições e o servidor processa essas requisições e produz respostas.

Uma resposta HTTP não precisa conter HTML, CSS e JavaScript. Ela pode transportar HTML, JSON, imagens, CSS, JavaScript, PDFs ou outros formatos. Quando uma página HTML referencia outros recursos, o navegador normalmente realiza requisições adicionais para buscá-los.

Características arquiteturais expressam qualidades que o sistema precisa apresentar, como desempenho, escalabilidade, disponibilidade, segurança, manutenibilidade e portabilidade. Como essas características podem competir entre si, decisões de arquitetura envolvem trade-offs.
