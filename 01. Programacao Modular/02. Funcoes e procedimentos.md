# Funções e procedimentos: abstrações de expressão e de comando

> **Contexto:** Estudo das duas unidades fundamentais de sub-rotinas na programação procedural e modular: as funções (abstração de expressão) e os procedimentos (abstração de comandos), analisando sua origem como o 1º critério de decomposição de software, seus efeitos colaterais e implementações práticas em C#.

---

## Introdução e o 1º critério de decomposição

Na história do desenvolvimento de software, à medida que os sistemas cresciam em complexidade, tornou-se impossível escrever todo o código em um único bloco contínuo de instruções (código monolítico).

Surgiu então o **1º critério de decomposição de programas (ou modularização funcional)**:

> *"Transformar cada passo principal do processamento em um módulo isolado."*

Em vez de ter um programa de mil linhas executando tudo em sequência, o desenvolvedor divide o fluxo em **etapas/passos principais**. Para transformar esses passos em código reutilizável e isolado, as linguagens de programação introduziram dois tipos primários de blocos executáveis (sub-rotinas):

1. **Procedimentos:** para passos cuja responsabilidade é **executar uma ação ou conjunto de comandos** (ex.: ler dados do usuário, imprimir relatórios, salvar no disco).
2. **Funções:** para passos cuja responsabilidade é **calcular e retornar um valor** a partir de dados de entrada (ex.: calcular imposto, validar um CPF, calcular fatorial).

---

## 1. Funções (Abstração de expressão)

Uma **função** é o que chamamos de **abstração de expressão**. Ela representa o mapeamento formal de dados de entrada em um resultado de saída, de forma análoga às funções algébricas da matemática, que mapeiam elementos de um *domínio* em uma *imagem*.

### Características principais das funções:
* **Foco no resultado:** seu objetivo principal é calcular e retornar um valor com base nos parâmetros recebidos.
* **Uso em expressões:** pode ser invocada diretamente dentro de atribuições, operações aritméticas ou testes condicionais (ex.: `bool ehValido = ValidarCpf(cpf);`).
* **Transparência referencial (ideal):** uma função pura calcula seu retorno sem causar efeitos colaterais (*side effects*) no ambiente externo (como imprimir na tela ou alterar arquivos).

---

### Exemplo prático 1: Função de cálculo do dígito verificador do CPF em C#

O cálculo do primeiro dígito verificador (DV) de um CPF é um caso perfeito de **abstração de expressão**: recebe os 9 primeiros dígitos (dados de entrada/domínio) e calcula o dígito verificador de saída (resultado/imagem).

#### Regra matemática do 1º Dígito Verificador:
1. Multiplica-se os 9 primeiros dígitos pelos pesos de 10 a 2.
2. Soma-se os produtos.
3. Calcula-se o resto da divisão da soma por 11 ($soma \bmod 11$).
4. Se o resto for menor que 2, o DV é `0`. Caso contrário, o DV é `11 - resto`.

```csharp
using System;

class ValidadorCpf
{
    // Função (Módulo de Cálculo): recebe 9 dígitos e retorna o 1º Dígito Verificador
    public static int CalcularPrimeiroDigito(string noveDigitos)
    {
        int soma = 0;
        int peso = 10;

        for (int i = 0; i < 9; i++)
        {
            soma += (noveDigitos[i] - '0') * peso;
            peso--;
        }

        int resto = soma % 11;
        
        if (resto < 2)
        {
            return 0;
        }
        else
        {
            return 11 - resto;
        }
    }

    static void Main(string[] args)
    {
        string novePrimeirosDigitos = "111444777";

        // Invocação da função em uma atribuição de expressão
        int digitoVerificador = CalcularPrimeiroDigito(novePrimeirosDigitos);

        Console.WriteLine("O primeiro DV para {0} é: {1}", novePrimeirosDigitos, digitoVerificador);
    }
}
```

### Exemplo prático 2: Função Fatorial em C#

Matematicamente:
$$0! = 1$$
$$n! = n \times (n-1)! \quad \text{para } n > 0$$

```csharp
using System;

class Calculo
{
    // Função: recebe 'n' e retorna o resultado numérico do fatorial
    public int Fatorial(int n)
    {
        int res = 1;
        if (n == 0 || n == 1)
        {
            return res;
        }
        else if (n > 0)
        {
            return n * Fatorial(n - 1);
        }
        else
        {
            return -1; // Valor de erro para entradas inválidas
        }
    }
}
```

## 2. Procedimentos (Abstração de comandos)

Um **procedimento** é o que chamamos de **abstração de comandos**. Ele representa uma sequência ordenada de passos que descreve **como uma tarefa ou ação é realizada**.

### Características principais dos procedimentos:
* **Foco na ação/execução:** seu objetivo é executar um conjunto de instruções ou tarefas sequenciais (cada passo do processamento de ação).
* **Ausência de retorno numérico/lógico:** em C#, procedimentos são representados por métodos com retorno `void`.
* **Efeitos colaterais e alteração de estado:** um procedimento frequentemente interage com o ambiente externo (imprimindo menus, limpando a tela ou salvando dados no disco).

---

### Exemplo prático: Procedimento de menu interativo em C#

Cada tarefa do menu representa um passo de processamento isolado transformado em procedimento:

```csharp
using System;

class MainClass
{
    // Procedimento 1 (Passo de Ação): limpar tela e exibir texto
    private static void Tarefa1()
    {
        Console.Clear();
        Console.WriteLine("Executando tarefa 1.");
        Console.ReadLine();
    }

    // Procedimento 2 (Passo de Ação): executa outra ação de E/S
    private static void Tarefa2()
    {
        Console.Clear();
        Console.WriteLine("Executando tarefa 2.");
        Console.ReadLine();
    }

    // Função auxiliar para gerenciar as opções de navegação
    private static bool MenuPrincipal()
    {
        Console.Clear();
        Console.WriteLine("Escolha uma opção:");
        Console.WriteLine("1) Executar tarefa 1.");
        Console.WriteLine("2) Executar tarefa 2.");
        Console.WriteLine("3) Sair");
        Console.Write("\r\nOpção: ");

        switch (Console.ReadLine())
        {
            case "1":
                Tarefa1(); // Invocação de procedimento
                return true;
            case "2":
                Tarefa2(); // Invocação de procedimento
                return true;
            case "3":
                return false;
            default:
                return true;
        }
    }

    public static void Main(string[] args)
    {
        while (MenuPrincipal()) ;
    }
}
```

## 3. Comparação sintética: Função vs. Procedimento

| Característica | Função (*Function*) | Procedimento (*Procedure*) |
| --- | --- | --- |
| **Passo no processamento** | Etapa de **Cálculo / Mapeamento** | Etapa de **Ação / Execução de Comandos** |
| **Abstração** | Abstração de **Expressão** | Abstração de **Comandos** |
| **Objetivo** | Mapear entradas e calcular um resultado | Executar uma sequência de ações/passos |
| **Retorno (`return`)** | Sempre retorna um valor de um tipo específico | Geralmente retorna `void` (sem valor) |
| **Exemplo de aplicação** | Cálculo de dígito de CPF / Fatorial | Exibição de menus / Limpeza de tela |
| **Invocação** | Usada dentro de expressões (`int dv = CalcularDV(cpf);`) | Invocada como uma instrução isolada (`ExibirMenu();`) |
| **Efeito colateral** | Desejável que não possua (função pura) | Frequentemente possui (E/S, mutação de estado) |
