### 7. Diretrizes arquiteturais, stack tecnológica e deploy na nuvem
* **Linguagem e Back-End:** Uso obrigatório de **C# com ASP.NET Core MVC**. Proibido o uso de PHP, Node puro no back-end, Python ou Java. A lógica de negócios deve ser escrita pela equipe, sem frameworks de geração automática de código que mascarem a separação das camadas acadêmicas.
* **Banco de Dados Relacional:** Exclusivamente **SQL Server**. Proibido o uso de MySQL, PostgreSQL, Oracle ou SQLite no ambiente oficial.
* **Front-End e Interatividade:** Uso de HTML5 e CSS (permitido o uso de bibliotecas visuais como Bootstrap e Tailwind CSS). O JavaScript é autorizado **estritamente para dinamismo e manipulação de interface**, sendo vedada a execução de regras de negócio ou validações críticas no cliente.
* **Hospedagem e Infraestrutura de Nuvem:** O deploy da aplicação e do banco deve ser realizado obrigatoriamente na **Microsoft Azure** (utilizando Azure App Service e Azure SQL Database). Não será aceito deploy na AWS ou Google Cloud Platform (GCP).
