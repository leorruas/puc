# Prompts de Estudo (LLM) - Projeto: Desenvolvimento de uma Aplicação Interativa

Use estes templates de prompt prontos com seu LLM (ChatGPT, Gemini, Claude, etc.) para sanar dúvidas, gerar exemplos práticos e exercitar seu conhecimento nesta disciplina.

---

### Brainstorming de Funcionalidades
```text
Aja como um Product Manager sênior. Com base no tema do meu projeto [DESCREVA O TEMA], ajude-me a definir o escopo de um MVP (Produto Mínimo Viável). Sugira as 5 principais funcionalidades e uma ordem lógica de priorização.
```

### Arquitetura do Projeto
```text
Proponha um diagrama de arquitetura de software de alto nível para uma aplicação que utiliza [TECNOLOGIAS, ex: React + Node + PostgreSQL]. Explique o fluxo de dados entre o cliente, a API e o banco de dados.
```
