# 02. Estruturas condicionais (if, else, switch, goto)

> **Contexto:** Estudo das estruturas de decisão e seleção simples, composta e múltipla em C#, Java, Python e JavaScript, acompanhado da análise histórica da instrução descontinuada `GOTO`.

---

## 1. Seleção simples e composta (`if`, `else if`, `else`)

### Como funciona
Avalia uma expressão booleana. Se a condição for verdadeira (`true`), o bloco associado é executado. Se for falsa (`false`), o fluxo passa para o próximo `else if` ou `else`.

### Comparativo de sintaxe

==== C# / Java / JavaScript
```csharp
int nota = 85;

if (nota >= 90) {
    Console.WriteLine("Aprovado com distinção");
} else if (nota >= 60) {
    Console.WriteLine("Aprovado");
} else {
    Console.WriteLine("Reprovado");
}
```

==== Python
```python
nota = 85

if nota >= 90:
    print("Aprovado com distinção")
elif nota >= 60:
    print("Aprovado")
else:
    print("Reprovado")
```

---

## 2. Seleção múltipla (`switch` / `match`)

### Como funciona
Avalia o valor de uma única variável contra múltiplos casos possíveis. É mais legível do que encadear dezenas de `if/else`.

### Comparativo de sintaxe

==== C#
```csharp
int dia = 2;
switch (dia) {
    case 1: Console.WriteLine("Domingo"); break;
    case 2: Console.WriteLine("Segunda"); break;
    default: Console.WriteLine("Dia inválido"); break;
}
```

==== Java
```java
int dia = 2;
switch (dia) {
    case 1 -> System.out.println("Domingo");
    case 2 -> System.out.println("Segunda");
    default -> System.out.println("Dia inválido");
}
```

==== Python (3.10+)
```python
dia = 2
match dia:
    case 1: print("Domingo")
    case 2: print("Segunda")
    case _: print("Dia inválido")
```

==== JavaScript
```javascript
let dia = 2;
switch (dia) {
    case 1: console.log("Domingo"); break;
    case 2: console.log("Segunda"); break;
    default: console.log("Dia inválido"); break;
}
```

## 3. O caso histórico do `GOTO` (Salto incondicional descontinuado)

### Como funciona e por que parou de ser usado
O `GOTO` é um comando de salto incondicional que faz a CPU interromper a sequência atual e pular para qualquer rótulo do programa.

* **O problema (*Spaghetti Code*):** O uso desenfreado do `GOTO` tornava impossível rastrear por onde o programa passava, gerando um código caótico e propício a bugs graves.
* **A substituição (Programação Estruturada):** O Teorema de Böhm-Jacopini (1966) e o manifesto de Dijkstra (1968, *"Go To Statement Considered Harmful"*) provaram que qualquer lógica computável pode ser feita sem o `GOTO`, utilizando apenas `if`, `switch`, `while` e `for`.

### Como era no C# / C (Obsoleto / Não Recomendado)

```csharp
// Exemplo histórico (NÃO UTILIZAR EM CÓDIGO MODERNO)
int x = 0;

Inicio:
x++;
if (x < 5) 
    goto Inicio; // Salta de volta para o rótulo 'Inicio' (substituído por um laço while)
```

* **Status nas linguagens:**
  * **C# / C / C++:** Ainda possuem a palavra-chave por compatibilidade histórica, mas seu uso é fortemente desaconselhado pelas boas práticas.
  * **Java:** `goto` é uma palavra reservada, mas não possui implementação (gera erro de sintaxe se usada).
  * **Python / JavaScript:** Não possuem a instrução `GOTO`.

---

## 4. Armadilhas comuns

* **Fallthrough no `switch`:** Esquecer o `break` em C#/JS faz a execução cair nos casos seguintes.
* **Indentação obrigatória:** Em Python, a indentação substitui as chaves `{}`.
* **Uso desnecessário de `GOTO`:** Tentar forçar o `goto` em linguagens modernas destrói a modularidade do código.
